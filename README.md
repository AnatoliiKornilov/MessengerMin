# MessengerMin

Данный проект является учебным проектом Анатолия Корнилова.
Он представляет из себя мини-мессенджер, в первой версии которого можно
переписываться лично с другими пользователями. Все пользователи имеют уникальное имя,
поэтому можно делать поиск по имени. Также можно создавать группы, добавлять туда участников и
удалять их оттуда. На данный момент не реализована возможность просматривать участников группы,
также в них нет ролей. Отправлять можно только текстовые сообщения. Есть адаптивный сайт.



Проект создан с целью научиться писать готовое полноценное приложение с C++-стеком и научиться деплоить. Я использовал такие технологии, как: C++23, pqxx, jwt-cpp, nlohmann-json, httplib, GTest 
для написания бэкенда, в качестве базы данных использовал SQL, фронтенд написан на чистых HTML, CSS, JavaScript. Сервер корректно и эффективно работает в многопоточном режиме, он развёрнут на https, 
защищён от SQL-инъекций, также я написал кастомный оптимизированный rate-limiter для защиты от спам-атак. На сервере порты для базы данных и бэкенда закрыты, поэтому нельзя к ним обращаться извне.
